Surge 断网守护 2.3.0

新增：设置 → 无响应超时
• 默认 200 ms，可输入 10～10000 ms 的整数，点击“保存”。
• 修改后下次开启守护生效；当前守护不重启、不解锁，继续使用开启时的原值。
• 界面区分“当前使用”和“下次开启”，数值保存在本机并在重启后保留。
• “恢复默认”会保存 200 ms，同样在下次开启生效。
• 明确的模式关闭或 Surge 退出事件不等待此超时。

升级到 2.3.0：本次更新检测引擎与权限组件。请先在旧版点击“关闭并恢复网络”，退出旧界面，再替换应用并重新开启守护。首次操作需授权一次，之后同版继续免密。
若已经替换应用而旧后台仍在运行，可用配套“恢复网络并暂停守护.command”先暂停恢复，再使用新版。
诊断中应出现 START 2.3.0 及你设置的毫秒值。


2.2.0 界面更新：原生磨砂窗口、胶囊导航、状态卡片与单一主按钮。
• 守护：当前状态、增强模式、系统代理和开机守护概览。只有后台确认正在守护时，双模式才显示“已开启”。
• 设置：开机启动开关、一次授权说明、检测规则和卸载入口。
• 诊断：读取当前状态和近期日志，支持展开和复制。

安装：将“Surge 断网守护.app”拖到 Applications，再从“应用程序”打开。

1. 先打开 Surge，同时开启增强模式和系统代理。
2. 在本应用点击“开启守护”。首次安装本版权限组件时，按 macOS 提示输入一次管理员密码。
3. 等待界面显示“正在守护”。

主按钮会按状态切换，每次只显示一个：
• 未开启或已关闭时，显示“开启守护”：首次安装后台及权限组件，并开启保护。
• 正在守护、启动或网络已锁定时，显示“关闭并恢复网络”：停止本次守护，按备份恢复网络。
• 操作过程中显示“正在开启…”或“正在关闭并恢复网络…”，暂时不可重复点击。
• 开机自动启动守护：默认勾选；后台在系统开机时启动，无需打开界面。
• 卸载后台组件：停止并恢复网络，再移除守护；应用本身可移到废纸篓。

点击窗口左上角关闭按钮后，窗口收起，应用保留在顶部菜单栏，Dock 图标隐藏。
菜单栏盾牌：绿色为正在守护，暗灰色为关闭或未开启，橙色为网络锁定，黄色为启动或状态待确认。状态通常约每秒刷新。
点击菜单栏图标，可显示主窗口、开启守护/关闭并恢复网络、查看诊断。
菜单里的“退出界面（守护继续运行）”或 Command-Q 会完全退出界面，菜单栏图标也随之移除；已开启的后台守护继续运行。重新打开应用可找回图标。
开机启动选项控制后台守护；登录后如需菜单栏图标，请打开本应用。
关闭守护后如果保留开机启动选项，下次开机会重新开启。
开启开机启动后，Surge 尚未就绪也会锁网，没有开机宽限期；可通过“关闭并恢复网络”解锁，再同时开启双模式后重新开启守护。

锁网以后不会自动解锁。恢复入口不依赖联网。
网络连接可能在恢复过程中断开，VPN 可能需要重新连接。

持续查询：连接就绪后，查询之间约等待 5ms，单次查询超时改为 200ms，减少短暂卡顿造成的误锁。
200ms 只用于等待无响应的查询；明确返回模式关闭或收到进程退出事件时，不会等满 200ms。
严格阈值可能把系统繁忙或短暂卡顿判成异常；不能保证真实断网仅几毫秒，也不能保证零数据包泄漏。

本包已做编译、自检、隔离模拟控制流程、图形界面检查和 DMG 校验。开发过程中未自动执行真实断网或开机重启验收；曾观察到本机经管理员授权后后台正常运行。
首次打开应用不会自动安装或启用守护。首次执行控制操作时安装权限组件，并完成一次管理员授权。
本版授权后，日常开启、关闭、修改开机设置、查看诊断和卸载无需重复输入密码，重启电脑后仍有效。
不保存电脑密码，也不修改 sudoers。权限组件只接受安装时授权用户和本版界面签名的预设操作，无法提交任意命令。
更换界面签名的新版、卸载重装、换用户或修复权限组件时，可能需要重新授权。

Apple Silicon 版本，最低部署版本 macOS 13，实际只在本机 macOS 26.3 验证。
使用本地 ad-hoc 签名，没有 Apple Developer ID 签名或 Apple 公证。如系统阻止运行，可在“系统设置 → 隐私与安全性”查看并允许此应用。

从命令行旧版（1.x）升级：先在应用中“关闭并恢复网络”，再点击“开启守护”安装新版。
从 2.0 / 2.0.1 升级：本次包含后台参数变更，请先关闭并恢复网络，退出旧界面，再替换 app 并重新开启守护。仅替换界面不会改变已经运行的旧后台阈值。
升级完成后诊断中应出现“START 2.0.2 … 单次查询超时 200ms”。
系统运行日志：/var/log/surge-disconnect-guard.log

从 2.0.2 / 2.0.3 升级到 2.1.0：退出旧界面后替换 app，再打开。第一次操作会请求安装权限组件的一次授权；安装该组件本身不会停止现有守护。后台检测引擎仍为 2.0.2，保持 200ms 超时。

权限组件日志：/var/log/surge-disconnect-control.log。通过应用“卸载后台组件”会一并移除权限组件。

从 2.1.0 升级到 2.2.0：退出旧界面后替换 app 再打开。界面签名已改变，第一次控制操作需重新授权一次，此后同版继续免密。检测引擎仍为 2.0.2、权限组件协议仍为 2.1.0，监控和恢复规则未变。
