# v2.3.0 验证范围

## 已完成

- C 和 Swift 以 warnings-as-errors 编译，核心、GUI 和权限组件自检通过。
- 42 项隔离脚本测试：14 项基础控制、11 项 GUI 控制、17 项权限控制。特权操作均使用临时目录和模拟命令。
- 默认 200 ms、范围边界、自定义值、原子保存和重读，以及非法输入、溢出、损坏配置的拒绝测试。
- 模拟 CLI 延迟 200 ms 时，自定义 60 ms 阈值触发内存模拟断网，800 ms 阈值正常通过。
- 权限通道核验内核审计令牌、用户身份、签名标识和固定代码哈希；拒绝越界或缺失的超时参数。
- 独立安全预览模式下验证输入、保存、非法值提示、当前/下次值区分、恢复默认、主按钮切换和导航。
- 应用及权限组件签名检查、DMG 校验与只读挂载版本检查。

## 实际验证边界

自检和构建不关闭真实网卡或 Surge 模式。完整的真实断网、恢复、首次管理员安装、开机启动及重启后配置加载，仍需要使用者在目标环境验证。模拟回调、状态查询耗时不能作为实际断网生效时间或延迟上限。

开发验证使用 Apple Silicon、macOS 26.3 和 Surge 6.10.0；最低部署目标为 macOS 13，未覆盖所有 macOS / Surge 组合。

模式解析依赖 Surge 自带 CLI 的 `feature list` 文本格式及交互提示符。Surge 改变输出格式时会按无法确认状态处理，需要更新并重新验证。
